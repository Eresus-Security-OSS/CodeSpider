# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately. Use GitHub's private vulnerability reporting for this repository, if available:

<https://github.com/Eresus-Security-OSS/CodeSpider/security/advisories/new>

If private reporting is unavailable, contact the project maintainers through the [Eresus Security OSS GitHub organization](https://github.com/Eresus-Security-OSS) and ask for a private channel. Do not create a public issue or pull request with exploit details.

When reporting, include the affected version or commit, the conditions needed to reproduce the issue, its impact, and a minimal proof of concept if one can be shared safely. Please avoid including real credentials, personal data, or data belonging to other users.

## What to expect

The maintainers will review the report, may ask for additional details, and will coordinate any fix and disclosure with the reporter. Response and remediation timelines depend on severity and maintainer availability; no fixed service level is promised.

## Supported versions

CodeSpider does not currently publish a formal version support window. If possible, report issues against the latest release and include whether earlier versions are affected.

## Security design

For the project's security boundaries and known limitations, see the [threat model](docs/threat-model.md). Please report gaps in those controls privately as well.
