# Phase 1 — Competitive Research & Technical Matrix

This matrix evaluates current AI code review engines, static/deterministic analyzers, workflow tools, and evaluation benchmarks based on documented architectures, public repositories, and published research.

## Technical Competitor Matrix

| Tool / Benchmark | Deployment & License | Core Context & Analysis Approach | Verified Capabilities | Key Limitations | Opportunity for CodeSpider (Apache-2.0) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **CodeRabbit** | Cloud SaaS (Enterprise self-hosted option); Proprietary | Multi-model ensemble + throwaway execution sandboxes (`cat`, `grep`, `ast-grep`, linters) | **Linked-Repo** multi-repo analysis; **CodeRabbit Verify** (CLI/API/browser) & **Runtime Verification** in throwaway sandboxes; 1-click suggestions | Requires explicit repo linking; Verify/Secure need env setup scripts/test data; agent-minute/tier caps; cloud-first data residency | Zero-setup **local bare-mirror cross-repo search**; **differential base-vs-head** container verification; **commit-history deleted-secret hunter**; **evidence state machine** |
| **Qodo (Merge / PR-Agent)** | SaaS + OSS (`github.com/the-pr-agent/pr-agent`, Apache-2.0) | Multi-agent PR suite + org governance rules + ticket/spec compliance | Org-wide rule lifecycle, companion test generation, multi-platform (GitHub/GitLab/Bitbucket/Azure) | Heavy Python stack; Gitea/Forgejo not primary; no differential base-vs-head sandbox reproduction | Pure Go single-binary Gitea/Forgejo daemon; **Go AST/types contract diff** + **persistent review memory** with policy simulation |
| **Greptile** | Cloud SaaS (Enterprise self-managed); Proprietary | Whole-codebase graph indexing + RAG over files/symbols/dependencies | Strong cross-file logical regression detection in large repos | SaaS indexing cost & latency; can produce verbose architectural comments; limited Gitea/Forgejo support | **Content-addressed incremental Go AST/types index** (`sha256` file cache) + **compact <1.2K-token deterministic brief** |
| **Graphite (Reviewer / Diamond)** | Cloud SaaS (GitHub-centric); Proprietary | Diff + stacked-PR stack context; intentionally quiet heuristic filtering | Very low noise; tight merge-queue & stacked-PR UX | GitHub-only; trades away deep security/invariant detection for quietness | **Security invariant tracking** (removed HMAC/auth/path guards) + **evidence-gated findings** |
| **GitHub Copilot Code Review** | Cloud SaaS (GitHub-native); Proprietary | Diff + repository file context inside GitHub ecosystem | Zero setup for existing Copilot Enterprise/Business orgs | GitHub-locked; suffers from author-model independence bias; limited adversarial verification | **Model-agnostic** (local/vLLM/OpenRouter/OpenAI) + **adversarial Red/Blue corroboration** + **self-hosted sovereignty** |
| **Gitar (by Sonar)** | Cloud SaaS; Proprietary | CI failure log analysis + autonomous fix loop integrated with SonarQube | Loops on CI failures until build passes; AST-informed checks | Proprietary SaaS; no self-hosted Gitea/Forgejo daemon | **`/ci` failure diagnosis** + collaborator-gated `/fix` + **container-isolated differential testing** |
| **Kodus AI** | Self-hosted / Cloud; **AGPL-3.0-only** | Web app + workers + BYO LLM across GitHub/GitLab/Bitbucket/Forgejo | Self-hosted privacy; custom compliance rules | Heavy multi-service stack; **AGPLv3 copyleft** prevents code reuse in Apache-2.0 | Apache-2.0 single Go binary with embedded UI, SSE, and zero external runtime deps |
| **OpenCodeReview (`ocr`)** | CLI / Agent (`github.com/alibaba/open-code-review`, Apache-2.0) | **Hybrid deterministic + LLM** Go pipeline | Solves LLM position drift via deterministic line mapping and rule filtering; high token efficiency | CLI-oriented rather than 24/7 Gitea webhook/reconciler daemon | Adopt **hybrid deterministic-first** architecture: deterministic AST/contract/hunk gates before LLM |
| **Semgrep** | CLI (`LGPL-2.1`) / Semgrep Pro (Proprietary) | Pattern + dataflow AST rules across 30+ languages | Fast deterministic taint/pattern scanning; SARIF output | Cross-file/interprocedural taint requires proprietary Pro engine; no LLM semantic reasoning | Pair deterministic AST/invariant analyzers with LLM reasoning and **SARIF 2.1.0** export |
| **CodeQL** | GitHub CLI/Engine (GitHub CodeQL Terms — non-commercial/GitHub restriction) | Relational database queries over extracted AST/CFG/dataflow | Deep interprocedural taint analysis | Restrictive license prohibits embedding in commercial/third-party SaaS without GitHub licensing; slow DB builds | Keep CodeSpider's Go core **pure stdlib Apache-2.0** (`go/ast`, `go/types`) with optional external SARIF ingestion |
| **Reviewdog** | CLI (`github.com/reviewdog/reviewdog`, **MIT**) | Parses linter output and maps diagnostics onto git diff hunks | Eliminates out-of-diff inline comment API failures; multi-forge reporter | Linter wrapper only — no semantic or cross-repo intelligence | Already implemented **diff-hunk line gating** (`ParseDiffValidLines`) inspired by this pattern |
| **Danger** | CI tool (`MIT`) | Programmable PR metadata rules (`CODEOWNERS`, labels, size, changelog) | Deterministic PR hygiene enforcement | No code/AST/security analysis | Integrated deterministic **auto-labeling**, **CODEOWNERS**, and **migration/IaC checks** |
| **SWE-PRBench** | Benchmark (`arxiv.org/abs/2603.26130`, 350 PRs) | Evaluates Config A (diff), Config B (diff+file), Config C (full AST/graph context) | Proved **Context Degradation Paradox**: bloated context drops contextual recall vs. compact ~2K-token prompts | Frontier models still achieve only ~15%–31% recall on raw human PR comments | Drives CodeSpider's **compact Deterministic Evidence Brief** design instead of raw AST dumping |
| **ReviewBench** | Benchmark (`github.com/review-bench/ReviewBench`) | Multi-source golden set (Human + Static + LLM); Grounded & Augmented Precision/Recall | Standardized severity-sliced precision/recall evaluation | Requires careful judge calibration and local reproducibility | Integrated `codespider bench` harness with ReviewBench-compatible JSONL schema + local fixtures |

## Open-Source License Compatibility Summary

- **Compatible for architectural inspiration / potential future integration:** `Apache-2.0` (`OpenCodeReview`, `PR-Agent`), `MIT` (`Reviewdog`, `Danger`).
- **Incompatible for embedding in Apache-2.0 CodeSpider core:** `AGPL-3.0` (`Kodus AI`), `LGPL-2.1` / Proprietary (`Semgrep` Pro), GitHub CodeQL Terms (`CodeQL`). CodeSpider keeps zero external Go dependencies in `go.mod`.
