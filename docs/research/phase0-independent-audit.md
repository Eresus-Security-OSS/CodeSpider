# Phase 0 — Independent Audit of CodeSpider

This document records an independent engineering and security audit of all 14 recently implemented subsystems in CodeSpider. Each subsystem was inspected directly at source level without relying on prior completion summaries.

## Summary of Critical & High Findings

| ID | Severity | Subsystem | File / Location | Finding | Remediation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| AUD-01 | **CRITICAL** | Proof-of-bug execution | `internal/tools/advanced_tools.go` | `runProofTest` executed `go test` directly on the daemon host filesystem/UID; untrusted PR `init()` / `Test*` code could read `codespider.yaml`, exfiltrate secrets, or access internal network services. | Disabled host execution completely; replaced with `internal/sandbox.Executor` requiring `sandbox.mode: container` (`--network=none --read-only --cap-drop=ALL --security-opt=no-new-privileges --pids-limit=64`) and always blocked on fork PRs. |
| AUD-02 | **CRITICAL** | Untrusted repo policy | `internal/worker/worker.go` | `.codespider.yaml` was loaded from the PR's untrusted `HEAD` worktree (`wtDir`), allowing a PR author to set `enabled: false` or `ignore_paths: ["**"]` and receive a green `success` commit status. | Load trusted `.codespider.yaml` policy from the repository's base branch via `workspace.ReadMirrorFile` when available; PR head only supplies non-security instructions wrapped in untrusted input envelopes. |
| AUD-03 | **CRITICAL** | Credential pinning & webhooks | `internal/workspace/workspace.go`, `cmd/codespider/main.go` | `gitAuthArgs` attached `Authorization: Basic` to any HTTP(S) `cloneURL` without verifying origin against `gitea.base_url`; `WebhookHandler` accepted unsigned requests when `webhook_secret` was empty. | Added `WithAllowedOrigin(cfg.GiteaBaseURL)` origin pinning in `workspace.Manager` and fail-closed `RequireSecret: !cfg.AllowUnsignedWebhooks` in `gitea.WebhookHandler`. |
| AUD-04 | **HIGH** | Cross-repo blast radius | `internal/tools/advanced_tools.go`, `internal/workspace/workspace.go` | `search_org_repos` searched all cached mirrors regardless of fork status or owner allowlist, creating a cross-repo exfiltration vector via prompt injection. | Enforced `policy.CapCrossRepoRead` (always denied for fork PRs) and owner/repo allowlist filtering (`allow_same_owner_cross_repo`, `cross_repo_allowlist`). |
| AUD-05 | **HIGH** | Skill path traversal | `internal/skills/skills.go` | `LoadSelected` joined `dir`, `name`, and `SKILL.md` without validating `name`, allowing `../` traversal via `.codespider.yaml` `skills:` or `/api/dry-run`. | Added strict slug validation (`^[a-z0-9][a-z0-9_-]{0,63}$`) and `workspace.ResolveSafePath` containment checks. |
| AUD-06 | **HIGH** | Head SHA race, dry-run state, SSE auth & evidence labels | `internal/worker/worker.go`, `cmd/codespider/cli.go`, `cmd/codespider/main.go`, `internal/agent/adversarial.go` | (a) `CreateReview` and `CommitAndPush` did not verify remote `Head.SHA` still matched `trigger.HeadSHA`. (b) `--dry-run` still opened/created `data/state.json`. (c) SSE passed `?token=` in URL query logs. (d) `repoconfig.AdversarialSecurity` was parsed but unwired. (e) `SIGHUP` only reloaded 3 fields. (f) `[BLUE-TEAM VERIFIED]` overstated LLM agreement as verification. | Added `VerifyHeadUnchanged` / `git ls-remote` pre-push SHA check, skipped `store.Open` on `--dry-run`, added `HttpOnly` HMAC-signed `cs_session` cookie (`POST /api/session`), wired `repoCfg.AdversarialSecurity`, expanded `SIGHUP` reload, and replaced `[BLUE-TEAM VERIFIED]` with explicit `evidence.State` (`model_corroborated`, `statically_supported`, `inconclusive`, etc.). |
| AUD-07 | **MEDIUM** | Docker deployment | `Dockerfile`, `docker-compose*.yaml` | No distroless `HEALTHCHECK` command; compose files lacked `cap_drop: ALL`, `no-new-privileges`, `pids_limit`, and memory limits. | Added `codespider healthcheck` subcommand + `HEALTHCHECK` in `Dockerfile` and container hardening in both compose files. |

## Per-Subsystem Audit Matrix (14 Inspected Areas)

1. **Cross-repository analysis (`search_org_repos`):** Works against bare mirrors via `git grep HEAD`, but lacked fork/owner isolation and was only useful when mirrors were already populated. Fixed via `policy.CapCrossRepoRead` + allowlists.
2. **Git forensics (`FileForensics`):** `git log -n 8 -s -L ...` works on macOS/Linux git (verified empirically) and falls back cleanly on new files; needed untrusted-output framing in agent prompts.
3. **Adversarial verification (`adversarial.go`):** Refuted findings were removed before `FlushReview`, which was good, but `repoCfg.AdversarialSecurity` was never wired and surviving comments were misleadingly labeled `[BLUE-TEAM VERIFIED]`. Fixed by wiring repo override and using `model_corroborated` / `inconclusive` evidence states.
4. **Intermediate commit secret detection (`security.ScanPatches`):** Accurately detects deleted-before-HEAD secrets across `CommitPatches` and masks previews, but needed fuzzing (`FuzzScanPatches`) and integration testing against real Git history.
5. **Proof-of-bug execution (`run_proof_test`):** Critical host RCE vector; replaced with container-only `sandbox.Executor` + differential base-vs-head runner.
6. **Model routing (`selectClient`):** `FastModel` and `RepoModel` routing works cleanly via shallow `llm.Client` copy; needed `SIGHUP` reload support.
7. **Sticky PR summaries (`UpsertStickyComment`):** Marker-based `PATCH` upsert works, but was tested only with mocked `httptest` rather than stateful PR comment persistence. Covered in `internal/testgitea` integration tests.
8. **Gitea permissions (`IsCollaborator`):** Fails closed on `/fix` for non-collaborators, but `IsFork` was not detected on PRs and webhook signatures were optional when `webhook_secret` was empty. Fixed via `IsFork` detection and `RequireSecret`.
9. **SSE event streaming (`/events`):** Broker ring buffer and `Flusher` work without blocking workers, but dashboard passed admin token in query string (`?token=`). Replaced with `HttpOnly` `cs_session` cookie.
10. **Dry-run mode (`--dry-run`, `/api/dry-run`):** Prevented Gitea writes, but CLI `--dry-run` still created `state.json` and did not prevent `audit.jsonl` / `memory.json` side effects. Isolated cleanly.
11. **`SIGHUP` reload:** Reloaded only `Skills`, `MaxSteps`, `MaxTokens`; ignored `LogLevel`, `FastModel`, `AdversarialSecurity`, `StickySummary`, `AlertWebhookURL`, `GiteaRepos`. Expanded to full runtime reload.
12. **Dashboard authentication:** `requireAdminToken` used `subtle.ConstantTimeCompare` properly, but query-param auth leaked tokens to logs/history. Added `POST /api/session` cookie auth.
13. **Reconciler (`StartReconciler` / `ReconcileOnce`):** Functional and race-safe, but lacked `IsFork` propagation on reconciled PRs. Fixed.
14. **Docker deployment:** Distroless runtime staged `git` and `git-remote-https` properly, but lacked `HEALTHCHECK` and compose security options (`cap_drop`, `no-new-privileges`, `pids_limit`). Fixed.
